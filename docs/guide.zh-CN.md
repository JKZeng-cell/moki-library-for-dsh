# MOKI资料库 for DSH

在 DSH 中管理文件、网页链接和文件夹，并与当前对话协作。适用于 DSH 桌面版 0.2.2-rc.1。插件包含资料库界面、数据库服务、Office 编辑器适配和十一组 DSH Agent 工具。

第一次使用可先看[五组图文演示](usage-demos.zh-CN.md)；按扩展名查能力请看[文件预览与编辑格式支持表](formats.zh-CN.md)。

## 使用

资料库工具栏的「资料库设置」和 DSH「设置 → MOKI资料库」同步保存以下选项。

- **界面语言**支持「跟随 DSH」（默认）、「简体中文」和「English」。选择后立即更新资料库及预览工具栏，重启后保留，不改变 DSH 自身语言。已打开的 Office 编辑器在重新打开后应用新语言，以保留未保存草稿。

- **文件预览打开方式**可选 DSH 主窗口、DSH 独立窗口或系统默认应用。默认跟随资料库位置。文件菜单中的「在侧边工作区打开」可单独指定这一次的去向。
- **自动映射 DSH 任务文件**默认关闭。开启后，新建或交付的本地文件会出现在「DSH 任务文件」中。相同路径只映射一次，关闭后保留已有映射。
- **对话输入框显示资料库**默认关闭。开启后，新会话的「资料库」按钮位于工作区与模式选择行的右侧，已有对话的入口位于输入框右上方。点击可浏览、搜索和多选文件，选好后用「添加附件」加入当前草稿，单个附件上限为 32 MB。
- **关于**显示插件版本、开发者 JKZeng 和[GitHub Issues](https://github.com/JKZeng-cell/moki-library-for-dsh/issues)，支持打开反馈页面和复制反馈地址。

- 点击左侧上方「插件」旁的「MOKI资料库」，在主窗口浏览。点击「侧边工作区」即可与对话并排使用，从侧边工具栏可以返回「主窗口」。右侧原生工作区的新增标签菜单也有资料库入口。
- 资料库和 Office 编辑器跟随 DSH 切换浅色和深色主题。侧边工作区会按宽度收起操作文字，浮窗使用 DSH 消息气泡和 Markdown 排版。
- 使用「新建」创建文件或虚拟目录，使用「添加文件」映射本地文件、文件夹或链接。点击路径栏的空白处或当前目录可输入和粘贴路径，回车定位。点击上一级箭头或祖先目录可返回。可在列表和卡片之间切换。
- 选择资料或编辑器中的文字后，对话输入区右上方会显示「选区加入对话」。开启「资料库」附件入口时，两个按钮并排显示。点击「选区加入对话」即可将引用加入当前草稿，继续输入要求或直接发送。DSH 可按引用读取全文、附件、表格和结构化预览。
- 在侧边工作区点击文件，会打开以文件名命名的 DSH 标签页。不同文件可以同时打开，切换标签可继续编辑各自的草稿，并与当前 DSH 对话协作。在主窗口点击文件，会打开可跨屏移动的系统独立预览窗口。再次打开同一文件会定位到对应的标签页或窗口。也可以从主窗口的文件菜单或预览工具栏把文件和草稿转到侧边工作区。独立窗口使用已安装的 Edge 或 Chrome 及插件专用临时配置。
- 在列表的名称空白、类型或日期列按住鼠标左键拖动即可框选，按住 Ctrl 可追加选择。从文件名、图标、卡片或「拖出文件」按钮起拖可拖动文件。Windows 支持把所选原文件拖到其他应用，也可按 Ctrl+C 后到目标应用按 Ctrl+V。其他平台的多文件拖出使用 ZIP。
- 从资源管理器拖入文件或文件夹可映射原路径，拖到已映射的本地文件夹会复制到磁盘。
- 资料库或文件夹为空时，内容区域显示「拖拽内容到此处添加到资料库」，支持文件、文件夹和链接；拖入时提示区域高亮，添加后自动显示资料。
- 鼠标在文件图标或缩略图上停留约 0.4 秒，会显示较大的预览气泡。图片按需生成，视频显示静音画面；移开、滚动、按 Esc 或开始拖动会关闭。列表、卡片和窄侧栏都支持。
- 在文件预览里按 **Alt+D** 或点击「DSH 对话」，对话会浮在当前预览窗口内。在另一块屏幕上也可以边看文件边对话。拖动标题栏移动浮窗，拖动边缘或四角调整大小。关闭浮窗可继续编辑，再次唤起可接着输入。点小鲸鱼旁的「新建会话」创建对话，点「历史会话」搜索并切换。浮窗使用 DSH 原生对话与输入区，支持附件、命令、引用、模型选择和工具审批。Excel 会传入工作表与选区地址，可要求 DSH 修改所选单元格。点击「保存」写回源文件，也可另存或放弃。
- 对话中可以让 DSH 查找、新建、编辑、整理资料，也可协作修改 Office 隔离草稿。源文件修改遵循 DSH 确认和文件版本检查，映射目录使用其已设置的读写权限。

## 选区与对话协作

在预览或编辑器中选中文字、单元格或压缩包条目，按 **Alt+D** 打开 DSH，在输入框上方点击「选区加入对话」可把当前文件和位置引用加入草稿。切换到对话输入框时保留选区。

- 选区引用只带所选内容与位置，不自动附带完整文本草稿。`moki_library_context` 默认返回结构化精简信息，正文预算 4,000 字符，按需用 `maxChars` 或 `detail=full` 扩展；单元格值只传一份，公式只返回非空项。引用加入输入框时正文预算为 1,000 字符，截断会明确标记。
- 普通文字、Word 文字、PPT 单一富文本样式内的文字及 Excel 连续选区可用 `context → edit_selection` 两次工具调用完成修改与回读验证。第二次只需 `selectionRef` 和新文字或二维单元格值，不再重复原文、位置和 API 查询。引用限当前会话和编辑器，10 分钟过期，成功后失效；原文或格式变化会拒绝修改。跨段落/富文本样式的 PPT 修改、大型或不连续单元格选区仍使用 Office 工具按需操作。修改均保留在草稿，保存方式不变。

- 文本记录 UTF-16 起止位置与行列；支持相同文字出现多次时只替换指定范围，并校验草稿 revision 和原选区内容。修改只进入草稿，可撤销，保存后写回源文件。
- Excel 记录工作表、单元格范围、值与公式；AI 修改和公式重算后自动刷新选区内容，无需重新点击表格。Word 记录页码、文字选区及准确字符偏移；PPT 记录页码、所选对象、位置与文字，进入文本框选中文字时记录该文本框内的精确范围。通过 Alt+D 或切换到对话，可修改所选位置并实时查看结果，再保存写回原文件。
- 深色模式下文本选区使用蓝色高亮和白色文字；图片等画面框选使用主题蓝色边框、半透明填充和内外描边，在明暗画面上都能辨认边界。
- PDF 默认预览支持直接选中文字及页码；扫描页可框选画面。OFD 可选择页面文字或框选，文本和压缩包分页保留段落字节位置或包内路径。
- 图片、视频、PDF、OFD 和 3D 预览工具栏的「框选区域与 DSH 协作」可传递真实区域截图、预览像素坐标、页码或视频时间。DSH 用 moki_library_context 读取当前选区图像；新选区不会误用旧截图，其他对话无法读取本会话的选区。
- moki_library_read 按文件签名和格式读取图片、压缩包目录、PDF/OFD 页面文字等，不把二进制当 UTF-8 文本。非文本/Office 格式的读取和视觉分析不代表可以直接编辑原文件；渲染文字偏移也不能当作源文件偏移。

## 文件预览与大小

除已有图片、音视频、PDF、Office、文本和网页预览外，增加以下能力：

内嵌编辑支持 DOCX、XLSX、PPTX、CSV、TSV、UNIVER 和所列常用文本扩展名；旧版 DOC/PPT 与 Apple Office 为有限的内容提取预览。完整扩展名、编辑能力、HEIC/HEIF 解码条件及未支持格式见[格式表](formats.zh-CN.md)。

| 格式 | 预览方式 |
| --- | --- |
| PSD / PSB、TGA、TIFF | 读取合并图像或转换为图片；解码器不支持的位深、颜色模式会提示使用默认应用 |
| AI、无扩展名文件 | 识别 PDF、图片或文本签名；含 PDF 兼容内容的 AI 可直接查看 |
| GLB / glTF / OBJ / STL / PLY / FBX | 本地 3D 查看，旋转、缩放和平移；OBJ 为几何预览，glTF 的附属资源需在同目录或子目录，专用压缩贴图等不支持时有错误提示 |
| TTF / OTF / WOFF / WOFF2 | 字体试览，可修改样本文字和字号，不安装到系统 |
| ZIP / ZIP64、RAR5、7z、TAR、GZIP、BZIP2、XZ、CAB、CCX、MOKIAPP | 只读目录、文件大小、搜索和分页，不自动解压；加密目录、旧版 RAR 或损坏的包交给默认应用 |
| OFD | 分页查看文字、图片与表格；复杂路径、部分签章和特殊图片编码仍以原应用为准 |
| INI、CONF、TOML、JSONL、字幕、脚本、翻译文件等 | 分段只读文本预览，识别 UTF-8、UTF-16 和 GB18030 |
| MOKI / MOKI-BOARD / MOKI-DATA | 导出数据或包目录预览，不执行导入，不代替完整白板渲染 |

映射、原文件流式预览、ZIP64/RAR5 目录和分段文本不设统一文件大小上限；浏览器拖入文件使用流式写入，取消或失败会清理未完成的副本，同名源文件不会被覆盖。可用空间、解码器和系统内存仍决定实际容量。

DOCX/XLSX/PPTX 的结构化预览按需读取压缩包内的文档数据，不再按压缩文件的 32 MB 大小拒绝打开；展开后的文档数据预算为 256 MiB，表格结构化预览仍显示最多 20 张表、5,000 行和 200 列，完整内容可进入 Office 编辑器。文本超过 5 MB 时改为只读分页，避免把一段预览误保存为整个文件。整体解码的 3D、字体、OFD 和 PSD 文件有 512 MiB 内存保护；PSD 合并图像最多 6,400 万像素。Office 内嵌编辑器的媒体快照限制和 DSH 对话附件的 32 MB 限制独立保留。

浏览器不能解码的音视频会尝试通过本机 PATH 中的 FFmpeg 转换播放，最多同时两路，支持已缓冲范围内跳转；没有 FFmpeg 或编码不支持时可以用系统默认应用播放。转换只用于预览，不改原文件。

实现依据：[yauzl ZIP64 流式目录](https://github.com/thejoshwolfe/yauzl)、[RAR5 格式说明](https://www.rarlab.com/technote.htm)、[ag-psd](https://github.com/Agamnentzar/ag-psd)、[Three.js](https://threejs.org/docs/)、[OFD 渲染器及已知限制](https://github.com/isee15/ofdjs)。

## 安装

### 让 DSH 完成安装

在 DSH 桌面端打开新会话，选择可用模型，然后复制 [README 中的完整安装指令](../README.zh-CN.md#install-with-dsh)并发送。指令包含固定版本的插件包直链、SHA256、环境检查、`desktop` 配置安装和版本验证。当前会话需要能够下载文件并执行本机终端命令。

等待 DSH 返回安装结果后，保存工作、手动完全退出并重新打开 DSH。安装任务进行中保持会话运行。重开后在插件列表确认「MOKI资料库」已启用，从侧边栏进入资料库；可用示例文件验证预览和 **Alt+D** 对话入口。

### 手动安装与排查

先启动一次 DSH 桌面端完成配置初始化，再完全退出。下载 [v0.1.61 Release](https://github.com/JKZeng-cell/moki-library-for-dsh/releases/tag/v0.1.61) 中的 `dsh-moki-library-0.1.61.tgz`，在桌面配置中通过 CLI 安装。Windows CLI 位于 DSH 安装目录的 `resources/runtime/cli/bin/dsh.cmd`；包含完整路径和 PowerShell 调用方法的步骤见 [README 的手动安装](../README.zh-CN.md#manual-install)。

下面的简写适用于 `dsh` 已在 PATH 且对应当前桌面端的情况。将路径换成安装包实际绝对路径；有自定义 `DSH_HOME` 时沿用桌面端的值。

```powershell
dsh plugin --profile desktop add 'dsh-moki-library@file:C:/Downloads/dsh-moki-library-0.1.61.tgz' --allow-build=sharp
```

安装成功后执行：

```powershell
dsh plugin --profile desktop list dsh-moki-library --depth 0
```

确认列出 `dsh-moki-library` 及预期版本，再重新打开桌面端。首次安装需要联网下载运行依赖。

| 情况 | 处理方式 |
| --- | --- |
| DSH 只能回复文字，无法下载或执行命令 | 使用上述手动安装步骤，在本机 PowerShell 中执行 |
| 终端提示找不到 `dsh` | 使用安装目录内的 `dsh.cmd` 完整路径；PowerShell 用 `&` 调用带空格的路径 |
| 安装成功但侧边栏没有入口 | 检查是否使用 `desktop` 配置及同一个 `DSH_HOME`，完全退出重开，并在插件列表确认已启用 |
| 下载或依赖安装失败 | 根据具体错误检查网络与环境，保留已下载的包供重试；以安装命令和版本检查结果确认状态 |

## 数据

首次运行会从同机 MOKI 工作台只读导入资料目录、标签、映射路径和排除项。之后两个应用分别维护索引。映射继续指向原文件，任一应用保存文件后另一方可以读取该文件的新内容。

Windows 默认资料库位于 `%USERPROFILE%\.dsh\moki-library`，包含资料索引、插件创建的文件和按 DSH 会话分开的编辑草稿。设置 `DSH_HOME` 时，资料库位于该路径下的 `moki-library`。Office 查看器首次打开时会在此目录准备运行文件。资料库核心操作可以在 MOKI 工作台退出时使用。

可选的扫描 PDF OCR 接口通过 DSH 进程的 `MOKI_LIBRARY_OCR_URL`、`MOKI_LIBRARY_OCR_MODEL` 和 `MOKI_LIBRARY_OCR_KEY` 配置。普通 PDF 的文本和预览可直接读取。

## 从源码构建

```powershell
npm ci
npm run build
npm test
npm pack
```

`vendor/moki` 保留资料库、预览和编辑器所需的 MOKI 模块。DSH 导航、原生会话、工具及运行时适配在 `src`，嵌入界面与 DSH 主题适配在 `web`。
