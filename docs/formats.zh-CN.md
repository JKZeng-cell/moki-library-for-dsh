# 文件预览与编辑格式支持

[English](formats.md) · [返回介绍](../README.zh-CN.md) · [用法演示](usage-demos.zh-CN.md)

以下依据 **v0.1.58 当前实现**整理。“可预览”表示有对应查看方式；“可编辑”表示可进入插件内的编辑草稿并保存。格式识别、完整还原版式、AI 理解和原文件编辑是不同能力，实际表现仍取决于文件内容、编码和运行环境。

## Office 与文本

| 格式 | 预览 | 插件内编辑 | 选区协作与注意事项 |
| --- | --- | --- | --- |
| Word `.docx` | 文档内容与编辑器视图 | 支持 | 读取所选文字与位置，修改后检查草稿、保存；复杂排版请与原应用核对 |
| Excel `.xlsx` | 工作表、值、公式和编辑器视图 | 支持 | 传递工作表和单元格范围；可修改值、公式，实时查看结果 |
| PowerPoint `.pptx` | 幻灯片内容与编辑器视图 | 支持 | 传递页码、对象和文本框内选区；不保证与 PowerPoint 所有效果完全一致 |
| `.csv`、`.tsv` | 表格 | 支持 | 在表格编辑器修改并保存分隔文本；这些格式本身不保存工作表样式和多表结构 |
| Univer `.univer` | 原生工作区 | 支持 | 可进入原生工作区草稿；协作能力取决于其中的文档、表格或幻灯片单元 |
| 旧版 Word `.doc`、PowerPoint `.ppt` | 提取内容预览 | 不支持 | 不是完整 Office 渲染；需要编辑时先在原应用另存为 `.docx` / `.pptx` |
| Apple `.pages`、`.numbers`、`.key` | 有限的内容提取预览 | 不支持 | 不等同于 Apple 原生版式渲染；新版本文件或包结构可能无法完整读取 |
| 常用文本、Markdown、JSON、HTML、代码 | 文本 / 对应预览视图 | 支持下方所列扩展名 | 可读取行列、精确字符范围并修改草稿；超过 5 MB 使用只读分页 |
| 配置、字幕、日志交换等扩展文本 | 分段文本预览 | 部分为只读，见下方清单 | 可按选中文字协作分析；不要将一页内容当成整个文件覆盖保存 |
| 旧版 Excel `.xls`、宏文档 `.xlsm` / `.docm` / `.pptm`、RTF、OpenDocument、受密码保护文件 | 不列为已支持的内嵌预览格式 | 不支持 | 使用默认应用；必要时自行转换为支持的格式，宏和格式信息可能无法保留 |

**可编辑文本扩展名：**

`txt`、`md`、`markdown`、`log`、`json`、`html`、`htm`、`xml`、`yaml`、`yml`、`js`、`jsx`、`ts`、`tsx`、`css`、`scss`、`less`、`py`、`java`、`c`、`cpp`、`h`、`hpp`、`cs`、`go`、`rs`、`sql`、`sh`、`ps1`。`csv` / `tsv` 通过表格编辑器处理。

**额外只读文本预览：**

`jsonl`、`ndjson`、`mjs`、`cjs`、`bat`、`cmd`、`ini`、`conf`、`cfg`、`toml`、`env`、`srt`、`vtt`、`ass`、`ssa`、`lrc`、`po`、`properties`、`url`。分页解码支持 UTF-8、UTF-16 和 GB18030；未知扩展名通过文件签名识别为文本时也使用只读预览。`.env` 文件可能含密钥，请只将需要的非敏感片段交给对话。

## 图片、PDF、音视频与其他格式

这一组以查看、读取与分析为主，不提供对应二进制文件的原位编辑器。

| 类别与格式 | 预览 / 读取方式 | 选区协作与限制 |
| --- | --- | --- |
| 图片：PNG、JPG/JPEG/JPE/JFIF、GIF、WebP、SVG、BMP、AVIF、ICO | 图片查看、缩放与平移；缩略图悬浮预览 | 可框选区域，传递实际区域画面和预览坐标；不等于图像修图或 SVG 源码编辑 |
| 设计图：PSD、PSB、TGA、TIF/TIFF | 读取合并图像或解码为图片 | PSD/PSB 需保存合并图像；不提供图层编辑，部分颜色模式和编码不支持 |
| HEIC / HEIF | 有条件的图像转换 | 依赖本机所用解码器构建；识别扩展名不代表所有设备拍摄的文件都可解码 |
| Illustrator `.ai` | 含 PDF 兼容数据时按 PDF 打开 | 不支持 Illustrator 路径、画板或图层编辑；无 PDF 兼容内容时使用默认应用 |
| PDF | 页面渲染、文字选择、画面框选 | 可传页码与所选文字；扫描页可传区域画面，是否能识别文字取决于模型视觉能力或另行配置的 OCR |
| OFD | 分页显示文字、图片和表格 | 可选文字或框选；复杂路径、签章及特殊图片编码以原应用为准 |
| 视频：MP4、WebM、M4V、MOV、OGV、MKV、AVI | 浏览器播放，必要时尝试本机 FFmpeg 兼容转换 | 可传当前时间和画面区域；实际支持由视频/音频编码决定，不提供剪辑或转码导出编辑器 |
| 音频：MP3、WAV、FLAC、AAC、M4A、OGG、Opus | 浏览器播放，必要时尝试本机 FFmpeg | 不等于自动转写，也不提供波形剪辑；音频分析能力由 DSH 配置决定 |
| 3D：GLB、glTF、OBJ、STL、PLY、FBX | 模型旋转、缩放和平移 | 可框选当前视角画面；OBJ 主要为几何预览，附属资源应在同目录或子目录，部分压缩贴图不支持；不提供建模编辑 |
| 字体：TTF、OTF、WOFF、WOFF2 | 修改试览文字和字号 | 仅改变试览，不修改字体文件，也不安装到系统 |
| 压缩包：ZIP/ZIP64/ZIPX、RAR5、7z、TAR、GZ/TGZ、BZ2、XZ、CAB、CCX、MOKIAPP | 只读目录、大小、搜索和分页 | 可传包内路径和选中条目；不自动解压、不编辑包内文件。加密目录、旧版 RAR、损坏文件使用默认应用 |
| MOKI、MOKI-BOARD、MOKI-DATA | 导出内容或包目录预览 | 不执行导入，也不替代完整白板渲染 |
| 网页链接 | 内嵌网页或跳转原网页 | 部分网站禁止内嵌或需要登录，不能保证读取所有页面 |
| 无扩展名 / 扩展名不符 | 按 PDF、常见图片、ZIP、PSD 或文本签名识别 | 只对实现中能识别的签名生效；识别失败时使用默认应用 |

## 容量与兼容性

- **资料映射和原文件流式预览没有统一大小上限**，仍受磁盘、内存、浏览器和解码器约束，不意味着任意大文件都能完整载入编辑器。
- **对话附件：单个 32 MB。** 把选区加入对话与附加整个文件是不同操作；大文件可按需讨论较小选区。
- **文本：超过 5 MB 使用只读分页。** 保持原文件完整性，不能把分页片段直接保存成全文。
- **DOCX/XLSX/PPTX 结构化预览：展开后的文档数据预算为 256 MiB。** XLSX 结构化预览最多显示 20 张表、5,000 行和 200 列；编辑器是另一条加载路径，其容量仍取决于运行环境。
- **3D、字体、OFD、PSD/PSB/TGA 等整体解码路径有 512 MiB 内存保护。** PSD/TGA 另有约 6,400 万像素保护；解码超时或格式不兼容时提示使用默认应用。
- **媒体兼容播放需要本机 FFmpeg。** 没有 FFmpeg 或编码仍不支持时，改用系统默认应用；预览转换不会改写原文件。
- 复杂 Office 布局、动画、嵌入对象、加密内容和特殊字体应在保存前检查。需要保留源文件时使用「另存为」。

上述是实现支持范围，不是所有格式变体逐一通过测试的承诺。完整使用流程见[五组用法演示](usage-demos.zh-CN.md)。
