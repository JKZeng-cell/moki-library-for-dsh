# Contributing

Thank you for improving MOKI Library. English and Chinese issues and pull requests are welcome.

Use Node.js 22.19+, run `npm ci`, `npm run build` and `npm test`. Browser/Office checks need Chrome or Edge. Keep changes focused and describe the behavior and validation in your pull request.

For bug reports, include the plugin and DSH versions, operating system, reproduction steps and a minimal synthetic file where possible. Remove private filenames, full local paths, conversation history, keys and personal information from logs and screenshots. Do not upload your live library database.

Please preserve editing drafts, exact selection boundaries, version checks and read-only preview behavior. Do not overwrite source files as part of a preview operation. See [public-release hygiene](docs/public-release.md).
